# Bao cao LaTeX

Thu muc nay chua ma nguon LaTeX cua bao cao cuoi ky Dealzy.

## Build

Tren Windows, chay:

```bat
build_report.bat
```

Hoac chay truc tiep XeLaTeX hai lan de cap nhat muc luc:

```bat
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

File PDF ket qua: `main.pdf`.
