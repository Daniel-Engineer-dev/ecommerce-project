\section{Frontend}

Các frontend đều dùng React + Vite, tổ chức theo trang và component. Một số trang quan trọng:

\begin{itemize}[leftmargin=1.2cm]
    \item Customer: \texttt{Home.jsx}, \texttt{SearchVouchers.jsx}, \texttt{VoucherDetail.jsx}, \texttt{Cart.jsx}, \texttt{Profile.jsx}.
    \item Partner: \texttt{App.jsx} chứa trải nghiệm quản lý chính cho đối tác, gồm dashboard, voucher, chi nhánh, xác thực code và báo cáo.
    \item Admin: \texttt{AdminDashboard.jsx}, \texttt{PartnerApproval.jsx}, \texttt{UserManagement.jsx}, \texttt{VoucherManagement.jsx}.
\end{itemize}

\section{Backend}

Server Express mount các nhóm route chính:

\begin{lstlisting}[language=JavaScript]
app.use('/api/vouchers', voucherRoutes);
app.use('/api/auth', authRoutes);
app.use('/api/admin', adminRoutes);
app.use('/api/partner', partnerRoutes);
app.use('/api/admin/vouchers', adminVoucherRoutes);
\end{lstlisting}

Các service sử dụng PostgreSQL thông qua \texttt{pg}. Mật khẩu được hash bằng bcryptjs, token đăng nhập dùng JWT. Email/SMS được đóng gói trong \texttt{utils/sendEmail.js} và \texttt{utils/sendSms.js}.

\section{Những điểm đã xử lý khi tích hợp nhánh}

Trong quá trình gom các nhánh role vào nhánh \texttt{partner}, nhóm đã:

\begin{itemize}[leftmargin=1.2cm]
    \item Merge chức năng admin từ nhánh \texttt{admin} vào nhánh \texttt{partner}.
    \item Giữ cả route partner và route admin voucher trong \texttt{application/server/index.js}.
    \item Giữ seed user có email/password hash để tương thích luồng auth mới.
    \item Sửa tên cột \texttt{reject\_reason} thành \texttt{rejected\_reason} để khớp schema database.
    \item Loại file tạm Office khỏi merge cuối.
\end{itemize}
