\chapter{Kiểm thử và trạng thái hoàn thành}

\section{Kiểm tra kỹ thuật}

Sau khi tích hợp các nhánh, nhóm đã kiểm tra:

\begin{itemize}[leftmargin=1.2cm]
    \item Cú pháp server bằng \texttt{node --check application/server/index.js}.
    \item Cú pháp service admin voucher bằng \texttt{node --check application/server/modules/admin/adminVoucher/adminVoucherService.js}.
    \item Build frontend admin bằng \texttt{npm run build}.
    \item Build frontend partner bằng \texttt{npm run build}.
    \item Build frontend customer bằng \texttt{npm run build}.
\end{itemize}

Các lệnh build đều hoàn thành thành công. Riêng admin build có cảnh báo chunk lớn từ Vite, đây là cảnh báo tối ưu bundle và không làm hỏng chức năng.

\section{Các phần đã đáp ứng tốt}

\begin{itemize}[leftmargin=1.2cm]
    \item Đủ ba vai trò chính: Khách hàng, Đối tác và Quản trị viên.
    \item Có cơ sở dữ liệu quan hệ và ERD.
    \item Có dữ liệu mẫu chứng minh hoạt động của hệ thống.
    \item Có luồng partner tạo voucher và admin duyệt voucher.
    \item Có cơ chế chỉ hiển thị voucher đã duyệt cho khách hàng.
    \item Có luồng đối tác xác thực voucher code.
    \item Có dashboard/báo cáo cơ bản cho admin và đối tác.
\end{itemize}

\section{Các phần còn thiếu}

\begin{itemize}[leftmargin=1.2cm]
    \item Checkout hoàn chỉnh từ giỏ hàng sang đơn hàng.
    \item Thanh toán mô phỏng trên backend và frontend.
    \item Phát hành voucher code tự động sau khi thanh toán thành công.
    \item Trang khách hàng xem voucher đã mua, QR mô phỏng và lịch sử đơn.
    \item Admin quản lý đơn hàng, xử lý hủy/hoàn tiền mô phỏng.
    \item Nhật ký hệ thống đầy đủ gắn với user thực hiện thao tác.
    \item Slide và video demo chưa được đưa vào repository.
\end{itemize}
