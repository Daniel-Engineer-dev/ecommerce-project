\section{Hướng dẫn chạy hệ thống}

\subsection{Backend}

\begin{lstlisting}
cd application/server
npm install
copy .env-sample .env
npm run dev
\end{lstlisting}

File \texttt{.env} chứa cấu hình kết nối PostgreSQL và các biến môi trường liên quan. Luồng Order/\allowbreak Payment trong đồ án sử dụng cơ chế mô phỏng/sandbox và không xử lý giao dịch tiền thật.

\subsection{Frontend}

Mỗi ứng dụng frontend chạy độc lập:

\begin{lstlisting}
cd application/client/customer
npm install
npm run dev

cd application/client/partner
npm install
npm run dev

cd application/client/admin
npm install
npm run dev
\end{lstlisting}

\section{Kiểm soát trước khi bàn giao}

\subsection{Chốt dữ liệu demo}

Dữ liệu demo Supabase được kiểm tra bằng script bảo trì trong thư mục database script. Script này khóa E-Voucher của các đơn không còn Paid và sinh bổ sung mã còn thiếu cho các đơn Paid.

\subsection{Chốt gói source}

Mã nguồn đóng gói lấy từ thư mục \texttt{application}, loại trừ \texttt{node\_modules}, \texttt{dist}, file môi trường thật và các file tạm build.

\section{Định hướng tiếp theo}

\subsection{Hoàn thiện sản phẩm sau demo}

Các hướng phát triển tiếp theo khi đưa hệ thống ra ngoài phạm vi demo:

\begin{enumerate}[leftmargin=1.2cm]
    \item Thay thanh toán mô phỏng bằng cổng thanh toán thật và quy trình đối soát.
    \item Bổ sung kiểm thử tự động cho luồng checkout, callback, hoàn tiền và redeem voucher.
    \item Chuẩn hóa quy trình seed dữ liệu demo để tránh dữ liệu cũ không khớp logic mới.
    \item Tối ưu bundle frontend bằng code splitting cho môi trường production.
\end{enumerate}

\subsection{Hoàn thiện trải nghiệm sau mua}

Phần phát triển tiếp theo tập trung vào bằng chứng kiểm thử giao diện và kịch bản demo cho trang lịch sử đơn, E-Voucher đã mua, trạng thái sử dụng, QR và điều kiện áp dụng.

\subsection{Mở rộng vận hành và kiểm thử}

Tiếp tục hoàn thiện test tự động, nhật ký hệ thống chi tiết hơn và quy trình deploy ổn định cho từng frontend.

\section{Kết luận}

Dealzy đã hình thành được hệ thống thương mại điện tử voucher với ba vai trò rõ ràng, cơ sở dữ liệu quan hệ và các luồng nghiệp vụ chính: tạo voucher, kiểm duyệt, công bố, mua voucher mô phỏng, phát hành E-Voucher và xác thực sử dụng. Báo cáo, script database và mã nguồn ứng dụng hiện đã đủ cơ sở để đóng gói bản nộp cuối cùng sau khi chốt thư mục source.
