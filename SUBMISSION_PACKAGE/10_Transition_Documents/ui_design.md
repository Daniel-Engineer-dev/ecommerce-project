# UI Design Notes

## Customer App

- Main flow starts at voucher discovery, not a marketing landing page.
- Key screens: Home, Search Vouchers, Voucher Detail, Cart, Checkout, Payment Status, Profile, Order History, My E-Vouchers, Support and Policy pages.
- Primary actions: add to cart, checkout, confirm payment, view code/QR, review, complain.

## Partner App

- Key screens: partner dashboard/profile, voucher management, voucher creation/editing and redemption/verification.
- Primary actions: create voucher, monitor approval status, verify code, mark e-voucher as used.

## Admin App

- Left sidebar separates operational domains:
  - Dashboard
  - Partner approval
  - User management
  - Voucher moderation
  - Order management
  - Complaint handling
  - Content management
  - System logs
- Admin screens use dense tables, filters and detail panels because admins need repeated scanning and operational control.

## Responsive Considerations

- Tables use horizontal overflow where needed.
- Forms stack on smaller screens.
- Important actions use clear buttons and status badges.
