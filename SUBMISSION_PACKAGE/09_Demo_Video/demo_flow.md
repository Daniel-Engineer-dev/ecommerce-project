# Demo Video Flow

This file is the recording script for the final demo video.

## Preparation

1. Start backend on port 5000.
2. Start customer app on port 5173.
3. Start partner app on port 5174.
4. Start admin app on port 5175 or another available port.
5. Use seeded accounts from the database script.

## Recording Sequence

1. Show customer home/search page and voucher detail.
2. Login as customer.
3. Add voucher to cart and open checkout.
4. Choose VietQR demo payment and confirm payment.
5. Show payment success page.
6. Open customer profile/order history and show e-voucher QR/barcode.
7. Login as partner.
8. Verify the e-voucher code and mark it as used.
9. Login as admin.
10. Show dashboard.
11. Show order management and order detail.
12. Show complaint management and response action.
13. Show content management.
14. Show system logs proving admin actions were recorded.

## Expected Result

The demo proves the full lifecycle: voucher publication, purchase, payment, e-voucher issuing, redemption, admin monitoring and audit logging.
